# 苹果指数

**用一天的生活记录，生成一颗属于今天的苹果。**

在线体验：[苹果指数](https://liu2908056-maker.github.io/apple-index/)

苹果指数是一款轻量的个人生活状态自评工具。记录饮水、睡眠、训练、营养和日常活动后，页面会计算当日指数，并展示各项表现与可改进之处。

## 功能

- **每日自评**：记录饮水、睡眠、训练或休息、蛋白质摄入、步数、中高强度活动和站立时间。
- **可选健康数据**：可补充睡眠评分、深睡时长、心率、血氧、压力等读数；不填写选填项也能计算。
- **指数与分项反馈**：查看 0–10 的苹果指数、生活评分、分项得分和改善提示。
- **本地记录**：支持保存当天结果、查看最近记录，以及复制结果。
- **自适应页面**：适配桌面与移动设备，并提供轻量动效和减少动态效果的系统偏好支持。

## 评分说明

苹果指数用于帮助回顾生活习惯，不是医疗评估。它根据项目中的规则将各项记录映射为分数，并生成综合结果；分数不代表医学意义上的健康水平，也不能替代专业诊断。

不同人的作息、运动量和身体状况存在差异。请把结果当作自我观察的参考，不要为了提高分数而过量饮水、过度训练或刻意追求某项读数。

## 隐私

填写内容、未完成的表单和保存的历史记录都存储在当前浏览器的 `localStorage` 中。项目代码不会主动将这些记录上传到服务器。清除浏览器站点数据会同时清除本地记录。

如果使用共享设备，请注意本地记录可能被同一浏览器的其他使用者看到。

## 本地运行

项目是静态网页，无需安装依赖。

1. 下载或克隆仓库。
2. 在项目根目录启动本地 HTTP 服务：

   ```bash
   python3 -m http.server 8765
   ```

3. 在浏览器打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。

建议通过 HTTP 服务打开，而不是直接双击 `index.html`，因为页面需要通过 `fetch` 读取苹果图片资源。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与表单 |
| `styles.css` | 布局、视觉样式、响应式规则和动效 |
| `app.js` | 表单交互、数据校验、本地保存、结果展示与图片加载 |
| `score.js` | 指数计算、分项评分与反馈规则 |
| `images/apple-0.b64` – `images/apple-10.b64` | 指数 0–10 对应的 JPEG 图片 Base64 文本 |
| `favicon.svg` | 网站图标 |

## 替换苹果图片

`images/apple-0.b64` 到 `images/apple-10.b64` 分别对应指数 0 到 10。当前网页读取的是 **Base64 编码文本**，不是直接读取 JPG 文件。

如需替换图片，请将新的 JPEG 图片编码为 Base64 文本，再按对应编号保存为 `apple-N.b64`。保持编号与指数对应，且不要将图片内容改成普通文字或带有无关前缀的内容。
