# 苹果指数测试

网页：https://liu2908056-maker.github.io/apple-index/

用今天能数得清的生活数字，算出 0 到 10 的苹果指数。数字越大，表示这一天越健康，也越有进步。

页面参考了网上的大水理论、大睡理论、薄肌理论，以及 Apple Watch 活力环和小米手环能读到的心率、血氧、压力、睡眠。公式在健康区间给满分，喝太多、睡太久、练太狠都会降分。没填的选填项不扣分。

数字只存在浏览器本地，不会上传。这是生活自评，不是医疗诊断。

## 本地打开

用浏览器打开 `index.html`，或在这个目录运行：

```bash
python3 -m http.server 8765
```

然后访问 `http://127.0.0.1:8765`。

## 苹果图

`images/apple-0.jpg` 到 `images/apple-10.jpg` 分别对应指数 0 到 10。换成同名文件后，结果页会显示新图。也支持 `.png`、`.jpeg`、`.webp`。
